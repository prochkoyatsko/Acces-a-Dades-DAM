Imports

const fs = require('fs').promises;   // versión con Promises → async/await

La propiedad se llama promises (en plural). require('fs').promise → undefined.

Síncrono vs asíncrono

  • Síncrono (readFileSync, writeFileSync): bloquea el programa hasta acabar. Simple, pero mala idea en servidores.
  • Callback: fs.readFile(ruta, 'utf8', (error, data) => {...}). El código de después se ejecuta antes que el callback.
  • Promises: fs.readFile(...).then(...).catch(...). Devuelve enseguida una promesa pendiente.
  • async/await: const data = await fs.readFile(...) dentro de una función async. El await suspende solo esa función; quien la llamó sigue ejecutándose.
async function llegir() {
  console.log('1');
  await fs.readFile('f.txt', 'utf8');
  console.log('3');
}
llegir();
console.log('2');            // salida: 1, 2, 3
Trampa

try/catch solo captura el rechazo de una promesa si haces await. Sin await, existeix() devuelve siempre true.

T3Flujos de datos (streams) y ficheros de texto

Por qué streams

readFile carga todo en memoria. Un stream da el fichero en chunks (fragmentos) y puedes procesar sin esperar al final. Regla: readFile para ficheros < 10 MB; streams para grandes; readline para línea a línea.

Eventos (¡cuál es de quién!)

ObjetoEventos
Readable (createReadStream)'data' (cada chunk), 'end' (no hay más datos), 'error'
Writable (createWriteStream)'finish' (tras end(), datos entregados al SO), 'close' (fichero cerrado, después), 'error'
readline (createInterface)'line' (línea completa), 'close' (fin del fichero), 'error'

Se escuchan con obj.on('evento', callback). Los streams son Event Emitters.

Readable

const fs = require('fs');
const rs = fs.createReadStream('f.txt', { encoding: 'utf8', highWaterMark: 1024 });
rs.on('data', chunk => { ... });   // chunk puede cortar una línea o palabra
rs.on('end', () => { ... });
rs.on('error', e => { ... });
  • Sin encoding → chunks como Buffer (bytes). Con 'utf8' → strings.
  • highWaterMark = tamaño máximo de cada chunk en bytes. Por defecto 64 KB (65536). No limita el tamaño del fichero.
  • Empieza a leer solo, sin llamar a nada más.

Writable

  • write(data) escribe sin cerrar (devuelve un booleano, no una Promise).
  • end(data?) escribe lo último y cierra. Después de end(), write() da error ('write after end') que llega al evento 'error'.
  • Tiene buffer interno; end() lo vacía antes de cerrar.
  • Por defecto createWriteStream vacía y reescribe el fichero (por eso Ex3 no acumula duplicados en series_importades.txt).
function esperarEscriptura(writeStream) {      // Ex3
  return new Promise((resolve, reject) => {
    writeStream.on('finish', () => resolve());
    writeStream.on('error', (error) => reject(error));
  });
}
const ws = fs.createWriteStream('informes/informe_diari.txt', { encoding: 'utf8' });
const acabada = esperarEscriptura(ws);   // registrar eventos ANTES de escribir
ws.write('...\n');
ws.end();
await acabada;                           // no seguimos hasta 'finish' (o el error va al catch)

Bytes vs caracteres y UTF-8

  • Todo son bytes (0–255). Un Buffer contiene bytes; Buffer.isBuffer(x).
  • En UTF-8: A = 1 byte, á = 2, € = 3, emoji = 4 (bandera = 8). Buffer.from('café').length = 5, pero 'café'.length = 4.
  • Codificaciones: utf8 (todo), ascii (128 caracteres, sin acentos), latin1 (Europa occidental).
  • Siempre 'utf8' para texto. readFileSync('f.txt') sin encoding → <Buffer ...>; se arregla con .toString('utf8').
  • Si conviertes chunks a mano con chunk.toString(), un carácter partido entre dos chunks sale mal (�). Con encoding:'utf8' en el stream Node no corta caracteres.

T4Serialización y ficheros JSON

Conceptos

Serializar = convertir un objeto a un formato que se pueda guardar o enviar (texto). Deserializar = el camino inverso. Analogía del mueble de IKEA desmontado en una caja.

writeFile solo acepta string o Buffer: pasarle un objeto da TypeError [ERR_INVALID_ARG_TYPE].

JSON (JavaScript Object Notation): legible, ligero (menos que XML) y universal. Tipos: string, number, boolean, null, array, object. Nada más.

Sintaxis estricta

  1. Claves siempre entre comillas dobles.
  2. Strings con comillas dobles (simples no valen).
  3. Sin coma final.
  4. Sin comentarios.

const fs = require('fs').promises;
const path = require('path');

async function main() {
  try {
    // 1. Crear carpetas (y las intermedias). Con recursive no falla si ya existen
    await fs.mkdir(path.join('diari', '2026'), { recursive: true });
    const ruta = path.join('diari', '2026', 'octubre.txt');

    // 2. writeFile: crea el fichero o lo SOBRESCRIBE entero
    await fs.writeFile(ruta, '=== Mi diario ===\n', 'utf8');

    // 3. appendFile: AÑADE al final, sin borrar lo que hay
    await fs.appendFile(ruta, '- Hoy he estudiado T2\n', 'utf8');
    await fs.appendFile(ruta, '- Mañana T3\n', 'utf8');

    // 4. readFile: leer todo el contenido como texto
    const contenido = await fs.readFile(ruta, 'utf8');
    console.log(contenido);

    // 5. readdir + stat: qué hay en la carpeta y cuánto ocupa
    const elementos = await fs.readdir(path.join('diari', '2026'));
    for (const nombre of elementos) {
      const info = await fs.stat(path.join('diari', '2026', nombre)); // readdir solo da nombres
      console.log(`${nombre}: ${info.size} bytes, ¿carpeta? ${info.isDirectory()}`);
    }

    // 6. copyFile: copia de seguridad (el original se queda)
    await fs.copyFile(ruta, path.join('diari', '2026', 'octubre_backup.txt'));
    console.log('Ahora hay:', await fs.readdir(path.join('diari', '2026')));
  } catch (error) {
    console.log('Error:', error.code, error.message);
  }
}
main();

Leer un log línea a línea con readline

Para qué sirve: Recorrer un fichero (aunque sea enorme) línea a línea, siempre con líneas completas.

06-readline.js
const fs = require('fs');
const readline = require('readline');

fs.writeFileSync('app.log', [
  '[2026-10-14T10:00:00.000Z] INFO: Sistema iniciado',
  '[2026-10-14T10:00:01.000Z] INFO: Serie añadida',
  '',
  '[2026-10-14T10:00:02.000Z] WARN: Config sin fecha',
  '[2026-10-14T10:00:03.000Z] ERROR: No se pudo crear el backup',
  '[2026-10-14T10:00:04.000Z] INFO: Serie añadida'
].join('\n') + '\n', 'utf8');

async function analizar() {
  // Crear la interfaz JUSTO antes del bucle (sin otros await en medio)
  const rl = readline.createInterface({
    input: fs.createReadStream('app.log'),
    crlfDelay: Infinity
  });

  const cuenta = { total: 0, vacias: 0, INFO: 0, WARN: 0, ERROR: 0 };
  for await (const linea of rl) {          // cada vuelta = UNA línea completa
    cuenta.total++;
    if (linea.trim() === '') cuenta.vacias++;
    else if (linea.includes('] INFO:')) cuenta.INFO++;
    else if (linea.includes('] WARN:')) cuenta.WARN++;
    else if (linea.includes('] ERROR:')) cuenta.ERROR++;
  }
  console.log(cuenta);                      // aquí ya se ha leído todo
}

Qué ha pasado

  1. createInterface recibe un stream en input, no una ruta. crlfDelay: Infinity hace que el salto de Windows (\r\n) cuente como uno.

    const texto = await fs.readFile(FICHERO, 'utf8');
    return JSON.parse(texto);

    if (error.code === 'ENOENT') return [];   // primera ejecución
    throw error;                              // otro error (p. ej. JSON roto): que suba
  }
}

  await fs.writeFile(FICHERO, JSON.stringify(tareas, null, 2), 'utf8');
}

  let nouId = 1;                                 // 2. modificar en memoria

  tareas.push({ id: nouId, texto, hecha: false });
  await guardar(tareas);                         // 3. guardar

}

Convertir CSV → JSON y XML

Para qué sirve: La estrategia de todas las conversiones: formato A → objetos → formato B.

16-convertir.js
const fs = require('fs').promises;
const { parse } = require('csv-parse/sync');
const xml2js = require('xml2js');

async function main() {
  try {
    await fs.writeFile('cataleg.csv',
      'nom,preu,categoria\nPortàtil,799.99,Informàtica\nLlibreta,2.50,Papereria\nLàmpada,abc,Il·luminació\nCadira,129.00,Mobiliari\n', 'utf8');

    // 1. CSV → objetos
    const files = parse(await fs.readFile('cataleg.csv', 'utf8'), { columns: true, skip_empty_lines: true });
    const convertits = files.map((f) => ({ nom: f.nom, preu: parseFloat(f.preu), categoria: f.categoria }));

    // 2. Validar: 'abc' → NaN → fuera
    const valids = convertits.filter((p) => Number.isFinite(p.preu));
    const productes = valids.map((p, i) => ({ id: i + 1, ...p }));
    console.log(`Leídas ${files.length} filas: ${productes.length} válidas, ${convertits.length - valids.length} descartadas`);

    // 3. Objetos → JSON
    await fs.writeFile('cataleg.json', JSON.stringify(productes, null, 2), 'utf8');

    // 4. Objetos → XML (id como atributo con $)
    const builder = new xml2js.Builder({ rootName: 'cataleg', xmldec: { version: '1.0', encoding: 'UTF-8' } });
    const xml = builder.buildObject({
      producte: productes.map((p) => ({ $: { id: p.id }, nom: p.nom, preu: p.preu, categoria: p.categoria }))
    });
    await fs.writeFile('cataleg.xml', xml, 'utf8');
    console.log(xml);
  } catch (error) {
    if (error.code === 'ENOENT') console.error(`No se encuentra el fichero: ${error.path}`);
    else console.error('Error en la conversión:', error.message);
  }
}

// SOLUCIÓ EXERCICI 5: SeriesTracker – Conversió entre formats
const fs = require('fs').promises;               // versió amb Promises → await
const { parse } = require('csv-parse/sync');     // només la funció parse; versió síncrona (sense await)
const xml2js = require('xml2js');                // aquí només per objectes → XML

// FUNCIÓ 1: CSV → objectes. Sense try/catch: els errors pugen a main()
async function importarCSV() {
  // PAS 1: llegir el fitxer com a text
  const text = await fs.readFile('import/series_noves.csv', 'utf8');
  // PAS 2: text CSV → objectes (tots els valors són STRINGS)
  const files = parse(text, {
    columns: true,            // la 1a línia dona nom a les propietats
    skip_empty_lines: true    // ignora les línies buides
  });
  // { titol: 'The Crown', temporades: '6', genere: 'Drama', puntuacio: '8.7' }
  // PAS 3: convertir els tipus (parèntesis → la fletxa retorna un objecte)
  const series = files.map((fila) => ({
    titol: fila.titol,
    temporades: parseInt(fila.temporades),   // '6'   → 6
    genere: fila.genere,
    puntuacio: parseFloat(fila.puntuacio)    // '8.7' → 8.7
  }));
  // PAS 4: mostrar
  series.forEach((serie) => {
    console.log(`Llegida: ${serie.titol} - ${serie.genere}`);
  });
  console.log(`\nTotal sèries importades: ${series.length}`);
  // PAS 5: retornar (qui crida ha de fer await)
  return series;
}

// FUNCIÓ 2: JSON → objecte → XML (Format A → objecte JS → Format B)
async function exportarConfigXML() {
  try {
    const jsonText = await fs.readFile('data/config.json', 'utf8');
    const config = JSON.parse(jsonText);
    console.log('Configuració llegida:', config);

    const builder = new xml2js.Builder({
      xmldec: { version: '1.0', encoding: 'UTF-8' },
      rootName: 'configuracio'            // → <configuracio>...</configuracio>
    });
    const xml = builder.buildObject(config); // cada propietat → un element

    await fs.writeFile('export/config.xml', xml, 'utf8');
    console.log('XML creat a export/config.xml');
  } catch (error) {
    if (error.code === 'ENOENT') {
      console.error(`No es troba el fitxer: ${error.path}`);
      console.error('Comprova que el fitxer és a la carpeta correcta');
    } else if (error instanceof SyntaxError) {
      console.error('Error: el fitxer config.json no conté JSON vàlid');
      console.error('Comprova que les cometes i les comes són correctes');
    } else {
      console.error('Error:', error.message);
    }
    // THROW ERROR: el tornem a llançar perquè main() sàpiga que ha fallat.
    // Sense això, main() mostraria "Conversions completades"
    throw error;
  }
}

Claves de la solución

  • importarCSV() no tiene try/catch: sus errores los captura el catch de main().
  • exportarConfigXML() captura el error para dar un mensaje concreto y luego hace throw error para que main() se entere. Sin ese throw, main() seguiría y mostraría «Conversions completades» aunque haya fallado.
  • Se distinguen errores con error.code === 'ENOENT' (y error.path da la ruta) y con error instanceof SyntaxError (JSON roto).
  • Los mensajes de error van con console.error; los normales con console.log.
  • parse() (csv-parse/sync) y buildObject() no llevan await; readFile y writeFile sí.
  • parseInt para temporades (entero) y parseFloat para puntuacio (parseInt('8.7') daría 8).
  • No hace falta csv-stringify: el ejercicio lee CSV pero no escribe ninguno.
  • El orden de las opciones del Builder (xmldec, rootName) no importa: es un objeto.
  • La solución no crea la carpeta export: se crea a mano en la Tasca 1 (mkdir data import export).
